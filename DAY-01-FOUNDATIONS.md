# Day 01 — Foundations for AI Architecture

## Objective

Build the broad technical vocabulary required to reason about AI systems as an architect.

An AI Architect does not need to implement every component. They need enough understanding to evaluate feasibility, dependencies, failure modes, and trade-offs.

## Learn

### Software foundations

- Python
- SQL
- Git
- APIs
- Linux
- Networking
- Operating systems
- Distributed systems
- System design

### Cloud and infrastructure

Understand:

- Compute
- Storage
- Networking
- IAM
- Containers
- Kubernetes
- Infrastructure as Code
- Managed AI services

### AI foundation

Understand the difference between:

- Traditional software
- Machine learning
- Deep learning
- Generative AI
- Foundation models
- LLM applications

## Architecture mindset

Start thinking in:

- components
- interfaces
- dependencies
- state
- data flow
- failure domains
- security boundaries
- scaling boundaries

## Exercise

Choose an AI feature you already use.

Draw its architecture and label:

- where data enters
- where data is stored
- where inference happens
- external dependencies
- authentication
- observability
- likely bottleneck
- likely failure point

## Deliverable

One architecture diagram plus a one-page explanation.

## Architect question

What would break first if traffic increased by 10x?
