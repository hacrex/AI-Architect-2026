# MLOps & AI Platform Engineering

## Objective

Design the platform that manages AI workloads throughout their lifecycle.

## Lifecycle

Data → Experiment → Evaluation → Registry → Deployment → Monitoring → Feedback → Improvement

## Tools and concepts

- MLflow
- Kubeflow
- GitHub Actions
- GitOps
- Model Registry
- Experiment Tracking
- DVC
- Continuous Evaluation
- Canary Deployment
- Blue-Green Deployment
- Rollback

## Platform concerns

Design for:

- developer self-service
- reproducibility
- environment separation
- secrets
- access control
- auditability
- deployment automation
