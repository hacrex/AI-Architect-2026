# Day 05 — Data Architecture for AI

## Objective

Understand how data architecture shapes AI architecture.

## Learn

### Data systems

- Data lakes
- Data warehouses
- Lakehouses
- Object storage
- Relational databases
- NoSQL databases

### Streaming

Study:

- Kafka
- event-driven pipelines
- batch vs streaming
- ingestion
- event processing

### AI retrieval

Understand:

- embeddings
- vector indexes
- vector databases
- metadata
- filtering
- hybrid search
- reranking

### Data quality

Architect for:

- freshness
- correctness
- lineage
- access control
- retention
- deletion

## Exercise

Design the data architecture for an enterprise knowledge assistant.

Include:

- source systems
- ingestion
- transformation
- document storage
- embedding pipeline
- vector database
- metadata store
- retrieval
- access control
- audit trail

## Deliverable

End-to-end data-flow diagram.

## Architect question

What happens when the source document is deleted or its permissions change?
