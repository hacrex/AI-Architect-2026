# AI Security, Governance & Responsible AI

## Objective

Treat security, governance, compliance, and responsible AI as architecture requirements from the beginning.

## AI security

Study:

- prompt injection
- data leakage
- model poisoning
- insecure tool use
- supply-chain risk
- secrets exposure
- excessive agent permissions

## Security architecture

Design:

- IAM
- least privilege
- secrets management
- network segmentation
- audit logs
- tenant isolation
- data classification

## Governance

Understand:

- AI risk assessment
- model governance
- data governance
- evaluation
- human oversight
- auditability
- retention

Useful frameworks include:

- NIST AI Risk Management Framework
- AWS Well-Architected Framework
- applicable regional AI regulations
